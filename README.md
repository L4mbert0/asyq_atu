# Асық ату

Браузерная 2D-адаптация казахской народной игры **асық ату**. Игрок управляет сақа, выбирает направление и силу броска, выбивает асыки за границу круга и соревнуется со вторым игроком или компьютером.

Проект рассчитан на широкую аудиторию: детей и взрослых, которые хотят познакомиться с традиционной игрой, а также на игроков, которым нужна короткая локальная партия на компьютере, планшете или телефоне.

## Возможности

- локальная игра вдвоём на одном устройстве;
- одиночная игра против компьютера;
- матчи на 1, 2 или 3 раунда и бесконечный режим;
- три скорости прицеливания и выбора силы: `0,75×`, `1,25×` и `1,75×`;
- шесть расстановок: линия, треугольник, ромб, круг, пирамида и случайный «Хаос»;
- до 15 асыков на поле в зависимости от расстановки;
- независимый выбор оформления асыков и сақа: классическое, «Казахские краски» и «Чёрно-золотое»;
- редактируемые ники игроков;
- локальные таблицы результатов для бесконечного режима и игры вдвоём;
- адаптивный интерфейс для компьютеров, планшетов и телефонов;
- автоматический перезапуск завершённого матча через 5 секунд.

Ники и выбранное оформление сохраняются в cookies. Лидерборды сохраняются в `localStorage` текущего браузера.

## Как играть

1. Выберите количество раундов, режим игры, скорость и расстановку.
2. Нажмите на сақа, чтобы запустить движущийся указатель направления.
3. Нажмите ещё раз, чтобы зафиксировать направление.
4. Дождитесь нужного значения циклического индикатора силы и нажмите в третий раз для броска.
5. За каждый асык, полностью покинувший центральный круг, активный игрок получает одно очко.
6. После остановки фигур оставшиеся асыки возвращаются на выбранную расстановку, а ход переходит сопернику.
7. Раунд заканчивается, когда на поле не остаётся асыков. Побеждает игрок, набравший больше очков.

Ник можно изменить нажатием на имя игрока на поле. Имя компьютера не редактируется.

## Правила и адаптация для браузера

В основу положен главный принцип традиционного асық ату: игроки по очереди используют сақа, чтобы выбивать асыки из ограниченной зоны. Для короткой и понятной браузерной партии правила адаптированы:

- вместо физического броска рукой используются два точностных выбора — направление и сила;
- столкновения, инерция, трение и отскоки рассчитываются физическим движком;
- выбитым считается асык, пересёкший внешнюю границу игрового круга;
- игроки всегда делают ходы по очереди независимо от результата броска;
- перед следующим ходом невыбитые асыки возвращаются в исходную расстановку;
- количество фигур зависит от выбранной схемы, а не фиксировано одним набором;
- в бесконечном режиме раунды продолжаются без ограничения, а лучший результат против компьютера записывается в локальный лидерборд;
- компьютер анализирует несколько траекторий в упрощённой копии физического мира, оценивает выбитые фигуры и их продвижение к краю, после чего выполняет один из лучших найденных бросков с небольшой погрешностью.

Скорость не меняет интеллект компьютера: она определяет только скорость движения стрелки направления и индикатора силы у игроков.

## Локальный запуск

### Требования

- [Node.js 24](https://nodejs.org/);
- [pnpm 11](https://pnpm.io/).

### Установка

```bash
git clone https://github.com/L4mbert0/asyq_atu.git
cd asyq_atu
corepack enable
pnpm install
pnpm dev
```

После запуска Vite выведет локальный адрес приложения, обычно `http://localhost:5173`.

Переменные окружения для текущей версии не требуются.

### Сборка и предпросмотр

```bash
pnpm build
pnpm preview
```

Готовая статическая сборка создаётся в каталоге `dist`.

### Проверки

```bash
pnpm lint
pnpm test
pnpm build
```

## Технологии

- **React 19** — интерфейс, панели настроек и лидерборды;
- **TypeScript 6** — типизация игровой логики и компонентов;
- **Phaser 3 + Matter Physics** — сцена, анимации, столкновения и движение фигур;
- **Vite 8** — разработка и production-сборка;
- **Vitest** — тесты расчёта броска, поведения компьютера и расстановок;
- **ESLint + Prettier** — проверка и форматирование кода;
- **CSS** — адаптивная вёрстка и визуальное оформление без отдельного UI-фреймворка.

## AI-инструменты

- **OpenAI Codex** использовался как помощник при проектировании, написании и проверке кода, тестов и документации.
- **OpenAI ImageGen** использовался для создания и вариации игровых ассетов: асыков, сақа, текстур и декоративных элементов. Полученные изображения были вручную отобраны, проверены на прозрачность и оптимизированы для браузера.
- Игровой компьютер не использует облачную генеративную модель: его решения выполняются локально детерминированным алгоритмом поиска и симуляцией физики.

## Заимствованные компоненты и материалы

Готовые игровые компоненты, макеты и фрагменты чужого проекта не копировались. Код интерфейса, игровая логика и визуальная композиция разработаны для этого проекта.

Используются сторонние open-source библиотеки из npm: React, Phaser/Matter, Vite, Vitest и инструменты TypeScript/ESLint. Их версии зафиксированы в `package.json` и `pnpm-lock.yaml` и распространяются на условиях собственных лицензий. Графические игровые ассеты созданы для проекта с помощью AI-инструментов; внешние изображения и коммерческие наборы ассетов не использовались.

## Известные ограничения

- мультиплеер работает только локально на одном устройстве; сетевой игры нет;
- нет аккаунтов и серверной синхронизации — ники, настройки и результаты относятся только к текущему браузеру;
- локальный лидерборд можно очистить вместе с данными сайта;
- компьютер использует эвристический перебор траекторий и не гарантирует идеальный ход во всех расстановках;
- физика и правила намеренно упрощены для короткой браузерной партии и не являются полной симуляцией всех региональных вариантов традиционной игры;
- звуковые эффекты пока не добавлены;
- игровой бросок рассчитан прежде всего на мышь и сенсорный экран; полноценное клавиатурное управление игровым полем пока отсутствует;
- для лучшей производительности нужен современный браузер с поддержкой Canvas/WebGL.
