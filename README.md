# Асық ату

Цифровая 2D-адаптация казахской народной игры на меткость.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Проект использует Node.js 24 и pnpm 11.19.0.

## Проверки

```bash
pnpm lint
pnpm test
pnpm build
```

## Статус

Подготовлен базовый React + TypeScript проект. Игровая механика будет добавлена следующим этапом.
